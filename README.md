# ระบบสต็อกยา · MEGA Clinic

เว็บแอปดูสต็อก ยอดใช้รายเดือน คำนวณโปรโมชั่น จัดการ SKU นำเข้าไฟล์ และอนุมัติผู้ใช้
ทำงานบน GitHub Pages (ฟรี) + Supabase โปรเจกต์ mega-receiving (ฟรี) ใช้บัญชีเดียวกับระบบรับของ

เว็บ: https://nutthamonr.github.io/mega-stock/

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าเว็บหลัก |
| styles.css | หน้าตา |
| config.js | ที่อยู่ Supabase และอีเมลบริษัทที่อนุญาต |
| app.js | เข้าสู่ระบบ สมัคร ขออนุมัติ เมนู โหลดข้อมูล |
| view-overview.js | ภาพรวมสต็อก + หน้ารายละเอียดสินค้า |
| view-promo.js | คำนวณโปรโมชั่น + บันทึกเป็นรูปภาพ |
| view-sku.js | จัดการรายการหลัก (SKU) |
| view-import.js | นำเข้าไฟล์ stock plan (.xlsx) |
| view-team.js | ทีม & สิทธิ์ (อนุมัติผู้ใช้) + โปรไฟล์ของฉัน |

## อัปเดตเว็บ

เปิด repository → กด **Add file → Upload files** → ลากไฟล์ที่แก้แล้วลงไป (ชื่อเดิมจะถูกแทนที่) → Commit
เว็บจะอัปเดตเองภายใน 1–2 นาที

## การเข้าใช้งาน

- คนที่มีบัญชีระบบรับของอยู่แล้ว: เข้าสู่ระบบด้วยอีเมลและรหัสผ่านเดิม → กรอกข้อมูลส่งคำขอ
- คนใหม่: กด "สมัครเข้าใช้งาน" ด้วยอีเมล @megaclinicthailand.com
- เจ้าของระบบอนุมัติในเมนู **ทีม & สิทธิ์** — อนุมัติแล้วทำได้ทุกอย่าง
